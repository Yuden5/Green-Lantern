# Green Lantern

**A greener city within everyone's reach.**

[🌐 Live Website](https://yuden5.github.io/Green-Lantern/) · [GitHub Repository](https://github.com/Yuden5/Green-Lantern)

Green Lantern is a GeoHackathon 2026 project exploring how data and urban policy can support more accessible and equitable green spaces in Bangkok, with a focus on **Green Bangkok 2030**.

## Website Pages

- **Home** — Introduces Green Lantern and the urban green-space challenges it explores.
- **Policy** — Presents the policy context and its connection to Green Bangkok 2030.
- **District Analysis** — Explores green-space distribution, accessibility, and potential sites for new or improved green spaces in Suan Luang district.

## Area of Interest

The project focuses on **Suan Luang, Bangkok**, exploring gaps in green-space access, the potential of underused urban land, and opportunities to improve neighbourhood access to green spaces.

## Getting Started

You will need Node.js and npm installed.

1. Clone the repository:

   ```bash
   git clone https://github.com/Yuden5/Green-Lantern.git
   ```

2. Navigate to the project folder:

   ```bash
   cd Green-Lantern
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal, usually `http://localhost:5173`.

To build the website for production:

```bash
npm run build
```
